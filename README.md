# Камень · Ножницы · Бумага

Игра для вечеринки. Каждый заранее выбирает 10 фигур подряд, потом все встречаются
в турнире на вылет. Сервер — Node.js без зависимостей, состояние живёт в памяти процесса.

## Запуск

```bash
npm start          # или: node server.js
```

По умолчанию `http://localhost:3000`, порт меняется через `PORT=8080 npm start`.

Чтобы играли с телефонов, раздай свой адрес в локальной сети: `http://<твой-ip>:3000`.

## Как играть

1. Каждый открывает `/`, вводит имя и выбирает 10 фигур подряд, жмёт «Выбрал».
2. Всех перекидывает в комнату `/room` — там видно список участников.
3. Админ (игрок с именем **boksh**) жмёт «Начать игру», потом «Следующий раунд».
4. Комната сама подтягивает состояние раз в 3 секунды.

## Правила пары

Фигуры сравниваются по порядку: первая с первой, вторая со второй и так далее.
Побеждает тот, чья фигура первой окажется сильнее; одинаковые — идём к следующей паре.
Если совпали все десять, побеждает тот, у кого меньше отпечаток выбора (см. ниже).

## Разбиение на пары

Для каждого игрока считается `sha256(имя + его фигуры)`. Игроки сортируются по этому
отпечатку и разбираются по парам подряд: первый со вторым, третий с четвёртым и так далее.
Порядок входа в игру ни на что не влияет — при тех же именах и фигурах сетка всегда одна и та же.

При нечётном количестве последний в сортировке проходит в следующий раунд без боя.
Победители пар встречаются в следующем раунде, пока не останется один — он и победитель.

## Что ещё стоит знать

- Имена уникальны, после старта игры новые игроки не подключаются.
- «Новая игра» у админа чистит всё и возвращает всех на экран выбора.
- Перезапуск сервера = новая игра: ничего никуда не сохраняется.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `server.js` | HTTP-сервер, роуты и API |
| `game.js` | Состояние, разбиение на пары, подсчёт пары |
| `public/index.html`, `public/join.js` | Экран выбора имени и фигур |
| `public/room.html`, `public/room.js` | Комната с опросом раз в 3 секунды |
| `public/style.css` | Оформление в духе Баухауса |

## API

| Метод | Путь | Что делает |
| --- | --- | --- |
| `GET` | `/api/state?name=…` | Полное состояние игры для опроса |
| `POST` | `/api/join` | `{name, moves}` — войти в игру |
| `POST` | `/api/round` | `{name}` — запустить раунд (только админ) |
| `POST` | `/api/reset` | `{name}` — сбросить игру (только админ) |
