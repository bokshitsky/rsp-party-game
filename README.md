# Камень · Ножницы · Бумага

Игра для вечеринки. Каждый заранее выбирает 10 фигур подряд, потом все встречаются
в турнире на вылет. Сервер — Node.js без зависимостей, состояние живёт в памяти процесса.

## Запуск

```bash
npm start          # или: node server.js
```

По умолчанию `http://localhost:3000`, порт меняется через `PORT=8080 npm start`.

Чтобы играли с телефонов, раздай свой адрес в локальной сети: `http://<твой-ip>:3000`.

## Как играть

1. Ведущий открывает `/` и жмёт «Создать комнату» — получается адрес вида `/room/VWAEAB`.
   Тот, кто создал комнату, ведёт в ней игру.
2. Ведущий кидает остальным ссылку на комнату. Каждый открывает её, вводит имя,
   выбирает 10 фигур подряд и жмёт «Выбрал». Ведущий тоже может сыграть.
3. Когда все собрались, ведущий жмёт «Объявить пары» — все видят, кто с кем играет,
   но не видят чужих фигур. Набор в игру на этом закрывается.
4. Ведущий жмёт «Запустить раунд» — показываются фигуры и результат каждой пары.
5. Дальше по кругу: объявить пары следующего раунда → запустить. Пока не останется один.

Комната сама подтягивает состояние раз в 3 секунды.

## Режим наблюдателя

У той же комнаты есть адрес `/room/<код>/watch` — там видно всё то же самое, но нельзя
ни войти в игру, ни вести её: формы выбора фигур и кнопок ведущего там просто нет.
Удобно вывести на телевизор или дать тем, кто не играет. Ссылка на него лежит в комнате,
рядом со ссылкой для игроков.

Пока идёт набор, на экране наблюдателя показывается ссылка для игроков — чтобы её
можно было просто переписать с экрана.

## Правила пары

Фигуры сравниваются по порядку: первая с первой, вторая со второй и так далее.
Побеждает тот, чья фигура первой окажется сильнее; одинаковые — идём к следующей паре.
Если совпали все десять, победителя выбирает монетка.

## Разбиение на пары

Для каждого игрока считается `sha256(имя + его фигуры)`. Игроки сортируются по этому
отпечатку и разбираются по парам подряд: первый со вторым, третий с четвёртым и так далее.
Порядок входа в игру ни на что не влияет — при тех же именах и фигурах сетка всегда одна и та же.

При нечётном количестве последний в сортировке проходит в следующий раунд без боя.
Победители пар встречаются в следующем раунде, пока не останется один — он и победитель.

## Кто есть кто

При первом заходе сервер кладёт в браузер куку `rsp_sid` — случайные 16 байт, `HttpOnly`,
живёт 12 часов. Игрок — это кука, а не имя: подделать ведущего, прислав чужое имя в запросе,
нельзя. Ведущим комнаты считается кука того, кто её создал.

В комнате внизу есть «Сменить игрока»: он выдаёт новую куку, прежний игрок остаётся
в игре, а ты заходишь ещё раз под другим именем. Так можно набить комнату с одного браузера
и всё проверить.

## Что ещё стоит знать

- Имена уникальны внутри комнаты; после объявления первых пар новые игроки не подключаются.
- «Новая игра» у ведущего чистит комнату и снова открывает набор, код комнаты сохраняется.
- Перезапуск сервера = все комнаты исчезли, ничего никуда не сохраняется.
- Комнаты, в которые 12 часов никто не заходил, удаляются сами.

| Файл | Что внутри |
| --- | --- |
| `server.js` | HTTP-сервер, куки-сессии, роуты и API |

## API

Личность во всех запросах берётся из куки, в теле её передавать не нужно.

| Метод | Путь | Что делает |
| --- | --- | --- |
| `POST` | `/api/rooms` | Создать комнату, вызвавший становится ведущим |
| `GET` | `/api/rooms/:code` | Состояние комнаты для опроса |
| `POST` | `/api/rooms/:code/join` | `{name, moves}` — войти в игру |
| `POST` | `/api/rooms/:code/draw` | Объявить пары раунда (только ведущий) |
| `POST` | `/api/rooms/:code/round` | Сыграть объявленные пары (только ведущий) |
| `POST` | `/api/rooms/:code/reset` | Собрать всех заново (только ведущий) |
| `POST` | `/api/switch` | Выдать новую куку, чтобы зайти другим игроком |
